# LunaPlayer 1.6.7

## Änderungen
- Audio- und Videodateien können aus Dateimanagern und anderen Anwendungen geöffnet werden.
- Videos werden an den integrierten VLC-Player übergeben; Musik bleibt beim GStreamer-Audio-Player.
- Mehrere ausgewählte Dateien werden gemeinsam übergeben.
- Neue Dateiöffnungen werden an die laufende LunaPlayer-Instanz weitergeleitet.
- Die interne Verbindung zwischen Programmstart und Player-Fenster wurde durch eine eindeutige Anmeldung stabilisiert.
- Die README und das Änderungsprotokoll wurden auf Version 1.6.7 aktualisiert und vereinheitlicht.
